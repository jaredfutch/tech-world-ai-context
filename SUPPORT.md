# Support

The Tech-World AI Context Framework is open source and provided under the MIT License.

## Community support

Use GitHub issues for:

- reproducible framework bugs;
- documentation defects;
- compatibility questions;
- proposed specification changes;
- sanitized feature requests.

Please include enough evidence to reproduce the problem without posting private or sensitive data.

## What is not included

Use of this repository does not include a promise of:

- individual implementation support;
- migration services;
- private architecture review;
- custom integrations;
- uptime or service-level guarantees;
- response-time guarantees;
- security certification;
- legal, regulatory, tax, or compliance advice.

## Commercial services

Organizations may engage Tech-World LLC separately for implementation, architecture, integration, migration, private deployments, or other professional services where offered.

Such services are separate from the MIT License and require their own scope and agreement.

## Security reports

Do not post credentials, tokens, customer data, exploit details, or other sensitive information in a public issue. Follow `SECURITY.md`.
